# Shahin Shajahan — Portfolio

Personal portfolio site for IT, networking, and web development work.

## Project structure

```
css-portfolio/
├── index.html          # Page markup
├── styles.css          # All styles (themes, layout, animations)
├── js/
│   ├── theme-init.js   # Applies saved theme before paint (no flash)
│   └── main.js         # Theme toggle, scroll reveal, custom cursor
└── images/
    ├── SS.png          # Logo (dark mode)
    ├── SS-light.png    # Logo (light mode)
    └── shahin.png      # Hero portrait
```

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server.
